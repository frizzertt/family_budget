# База данных "Семейный бюджет"

Папка содержит минимальный комплект SQL-скриптов для PostgreSQL/pgAdmin.

## Порядок запуска

1. Создайте в pgAdmin новую базу данных, например `family_budget_db`.
2. Откройте Query Tool для этой базы.
3. Выполните `01_schema.sql`.
4. Выполните `02_seed_data.sql`.
5. Выполните `03_check_counts.sql` и проверьте количество записей.
6. Выполняйте запросы из `04_complex_queries.sql` по одному.

`02_seed_data.sql` создает 1 000 000 записей в основной таблице `purchase_payments`.
Если нужно быстро проверить работу скрипта, временно замените `generate_series(1, 1000000)`
на меньшее значение. Для итоговой сдачи верните 1 000 000.

## Таблицы

- `families` — семьи;
- `family_members` — члены семей;
- `product_types` — типы товаров и услуг;
- `products` — товары;
- `accounts` — счета членов семьи;
- `income_transactions` — доходы;
- `purchase_payments` — платежи по покупкам.

Основная сущность курсовой работы: `purchase_payments`.
